Более безопасное сопряжение с Mac

• Новое сопряжение с Mac сохраняется только после подтверждения на iPhone и Mac. Если ответить «нет» в Terminal, оба устройства останутся несопряженными. Обновите Walnut Agent на Mac с помощью brew upgrade walnut-agent.
• В разделе «Информация об устройстве» тепловое состояние и другие значения статуса отображаются на вашем языке.
• Более понятный статус Mac Agent после завершения сопряжения.
• Walnut сообщает, когда Walnut Agent на вашем Mac устарел. Старые версии продолжают работать.
