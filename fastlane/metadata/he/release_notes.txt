קישור בטוח יותר ל‑Mac

• קישור חדש ל‑Mac נשמר רק לאחר שתאשרו גם ב‑iPhone וגם ב‑Mac. תשובה שלילית ב‑Terminal תשאיר את שניהם לא מקושרים. עדכנו את Walnut Agent ב‑Mac באמצעות brew upgrade walnut-agent.
• Device Information מציג את המצב התרמי וערכי סטטוס נוספים בשפה שלכם.
• סטטוס ברור יותר של Mac Agent כאשר הקישור מסתיים.
• Walnut מודיעה לכם כאשר Walnut Agent ב‑Mac אינו מעודכן. גרסאות ישנות יותר ממשיכות לעבוד.
