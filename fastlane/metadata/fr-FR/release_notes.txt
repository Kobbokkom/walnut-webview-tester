Walnut parle votre langue

• Chaque écran, demande d’autorisation et message est désormais traduit dans toutes les langues prises en charge.
• Mac Agent se connecte en quatre étapes claires : installer, activer, jumeler, démarrer une session.
• « Autoriser les actions sur la page » ignore uniquement les demandes de confirmation pour la page ouverte. Le stockage, les suppressions et les détails réseau demandent toujours une confirmation.
• L’état de Mac Agent reste visible lorsque la barre d’outils est masquée.
